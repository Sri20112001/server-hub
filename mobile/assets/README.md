# Assets

Place the following files here before building:

- `icon.png` — 1024×1024 app icon (use Server Hub branding, dark background #121316 with amber ⚙ glyph)
- `adaptive-icon.png` — 1024×1024 Android adaptive icon foreground (add back to app.json `adaptiveIcon.foregroundImage` when ready)
- `splash.png` — 1284×2778 splash screen (add back to app.json `splash.image` when ready)
- `notification-icon.png` — 96×96 monochrome white notification icon (add back to app.json expo-notifications plugin config when ready)

Color reference from Server Hub design tokens:
- Background: #121316 (abyss)
- Accent: #f59e0b (ember)
